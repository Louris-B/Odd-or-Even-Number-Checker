# Odd-or-Even-Number-Checker
## Description:
A program that checks if the inputted whole number is odd or even using modulo operator.

## How to run:
1. Open the program in an IDE that you desire (as long as it supports Python 3).
2. Run the program.
3. Enter a positive value for num.
5. Check whether the result is odd or even.

## Input Needed
num -

## Sample Outputs
Enter a positive whole number: 2
2 is even.

Enter a positive whole number: 5
5 is odd.

Enter a positive whole number: -5
The value must be positive, please try again.
